## ⚙️ Getting Started

### 📦 Install dependencies

```bash
pnpm install
````

### 🚀 Run development server

```bash
pnpm dev
```

Open your browser at:

```
http://localhost:3000/
```

---

## 🛠️ Build for Production

```bash
pnpm build
```

To run the production build locally:

```bash
pnpm start
```

---

## 🧪 Testing

Run unit tests:

```bash
pnpm test
```
